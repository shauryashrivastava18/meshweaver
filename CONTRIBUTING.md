
# Contributing to MeshWeaver

## Development Guidelines

1. Keep code modular and easy to understand.
2. Use meaningful variable and function names.
3. Follow Python coding conventions.
4. Handle errors wherever required.
5. Avoid modifying another member's modules without discussion.

## Testing Guidelines

1. Write tests for newly implemented functionality.
2. Run existing tests before submitting changes.
3. Fix failing tests before integration.
4. Verify that existing functionality continues to work.

## GitHub Workflow

1. Work on your assigned development branch.
2. Make meaningful commits.
3. Push changes regularly.
4. Create a Pull Request for code review.
5. Coordinate with the team before merging.

## Team Collaboration

Every team member should document their implementation, test results and pending tasks.

The goal is to maintain reliable, readable and maintainable code throughout MeshWeaver development.
